# Fork Notes

`kylin-feng/Feynman-Reader` is a fork of [`HachikoJ/Feynman-Reader`](https://github.com/HachikoJ/Feynman-Reader) (MIT, prod at <https://reader.deline.top/>).

This fork exists to verify the push channel and document a reproducible local setup under the network conditions I had at fork time. No production code was changed; the official README/CHANGELOG/source are untouched except for one trailing line in `README.md`.

## What this fork contains on top of upstream

- **`FORK_TEST.md`** — the Contents-API push test marker (commit `6128d1b`).
- **`README.md`** — upstream README with one extra trailing line recording the proxy path used to push (commit `2e155a2`).
- **`docs/fork-setup/`** — full setup, proxy, env, and run notes ([README](docs/fork-setup/README.md)), plus the bookshelf screenshot from a successful local run.
